# Unity Event Toolkit

**Unity Event Toolkit** is a custom Unity Editor tool that makes it easy to find, inspect, and clean up `UnityEvent` bindings in your scenes.

---

## Features

- Scan All UnityEvents — automatically find all UnityEvent fields across your scene(s).
- Search & Filter — search by GameObject name or event field name, filter for All, Valid, or Broken listeners.
- Hierarchy View with Icons — browse GameObjects in a collapsible tree view with foldouts and parent/child relationships.
- Auto-expand parents when searching — so you can see matches in context.
- Multi-select support — hold Shift to select multiple GameObjects in the tree.
- Auto-ping selected objects — selecting a GameObject highlights it in the Unity Hierarchy.
- Event Inspector Panel — inspect UnityEvents, see listeners, and remove broken ones easily.
- Expand/Collapse All — quickly expand or collapse the entire hierarchy tree.

---

## Installation

**Option 1: Download ZIP**
1.  Download as **ZIP**.
2. Extract and drop the folder into your `Assets` directory.

**Option 2: Download Unity Package**
1. Go to the **[Releases](https://github.com/haruchanz64/UnityEventToolkit/releases)** tab.
2. Download the latest `.unitypackage` file.
3. Import it into your project using `Assets > Import Package > Custom Package`.

---

## Usage

- Open the toolkit: `Tools > Unity Event Toolkit`.
- Use the left panel to navigate your hierarchy.
- Click a `GameObject` to see its UnityEvents on the right.
- Search, filter, and clean up broken listeners easily.
